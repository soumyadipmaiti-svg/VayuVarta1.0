1 Project Overview

Vayu Varta is a full-stack AI-powered weather intelligence platform designed for rural and urban India. It provides real-time weather data, a voice-enabled AI assistant (VayuGPT) that speaks Bengali, Hindi, and English, and a predictive alarm system that warns users before disasters strike.

⭐ Key Innovation: "Before the Disaster"

Instead of reacting to weather events, Vayu Varta predicts them and gives users a countdown timer before the disaster hits — turning a reactive weather app into a proactive early-warning system.

Smart Input Handling

⌨️ Typed Input
User types question → AI responds with text only. No voice output.
🎤 Voice Input
User speaks → Speech Recognition captures → AI responds with text + voice.
🔇 Auto-Send
After 2.5 seconds of silence, voice input auto-sends to AI. No button tap needed.

Streaming Architecture

How Streaming Works (ChatGPT-like speed)
1. Backend fetches weather + conversation history in parallel (~0.3s)
2. Gemini starts generating tokens immediately
3. Each token is sent via Server-Sent Events (SSE)
4. Frontend renders text token-by-token with a blinking cursor
5. First word appears in ~0.5 seconds, full response in 2-3 seconds

Language Matching

7 🚨 AI Weather Alarm System — Key Innovation
⭐ "Before the Disaster" — Predictive Early Warning

AI-Prioritized Alert Logic

Why This Is Different From Other Weather Apps
Other apps: Notify for every weather change → notification fatigue → users ignore alerts
Vayu Varta: AI considers hazard severity × proximity to user × timing → only alerts when it actually matters

Example: Heavy rain occurring 50km away → no alert. Flash flood risk within 5km of user → 🔴 CRITICAL ALARM with countdown.

12 Voice System Architecture
🎤 Speech Recognition (Input)
  • Web Speech API (browser native)
  • Continuous mode — keeps listening
  • Accumulates all spoken text
  • Silence auto-send — 2.5s silence = auto-send
  • Live transcript shown while speaking
  • Red pulsing indicator when active
  • Manual stop available (tap mic again)
🔊 Speech Synthesis (Output)
  • Fish Audio API — natural voices
  • Bengali voice: warm female (0.75x speed)
  • Hindi voice: clear male (0.85x speed)
  • English voice: default (1.0x speed)
  • Auto-triggers when user spoke input
  • Manual "Read aloud" button on any message
  • Slower speed for rural clarity

Bengali Detection Rules

How We Detect Bengali / Banglish Input
Unicode Bengali: Any character in 0980-09FF range → Bengali
Banglish words: ami, ki, ache, hobe, kemon, bhalo, na, o, ebong, tarpor, khub, onek, chol, jao, dekho, bolo, bsha, brishti, gorom, thanda, batash
Hindi words: hai, kya, bahut, accha, bura, garam, sardi, baarish, aaj, kal, din, raat, subah, dopahar, sham, mujhe, tumhe, hamare
English: Everything else defaults to English
