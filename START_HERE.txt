  Q: "Port 3000 already in use"
  A: Close other dev servers or use: npm run dev -- --port 3001

  Q: "Backend not connecting"
  A: Make sure backend is running on port 8000 first

  Q: "Voice not working"
  A: Use Chrome or Edge browser. Allow microphone access.

  Q: "Changes not showing"
  A: Hard refresh: Ctrl + Shift + R

  Q: "Supabase error"
  A: Check .env has correct SUPABASE_URL and SUPABASE_SERVICE_KEY
