# VayuVarta — Professional Weather Icon System
## Design brief for an AI coding/design assistant

Create a complete, cohesive weather icon system for a modern professional weather app called **VayuVarta**.

### Visual direction
- Style: premium, minimal, aesthetic, professional, modern SaaS/mobile weather UI.
- Strong visual consistency across every icon.
- Use clean geometric forms with smooth curves and precise spacing.
- Prefer a **soft glassmorphism / liquid-glass compatible** appearance.
- Icons should look excellent on dark and light backgrounds.
- Avoid cartoonish, childish, overly detailed, or generic emoji-like artwork.
- Use subtle glow/highlight effects only where appropriate.
- Keep icons recognizable at small sizes.
- Use rounded line/solid hybrid forms with consistent stroke weight.
- No text inside icons.
- No brand logo inside weather icons.
- Keep the same visual language, perspective, lighting and proportions across the entire set.

### Recommended technical style
- Primary format: SVG, scalable and crisp.
- Also support PNG/WebP exports if needed.
- Suggested icon canvas: 64×64 or 96×96.
- Use transparent backgrounds.
- Consistent optical padding around every icon.
- Design for both 24px UI use and larger weather-card use.
- If color is used, keep it restrained and premium; icons should also work in monochrome.
- Suggested palette direction: white/near-white highlights plus controlled cyan, blue, violet, amber and cool-gray accents. Do not make every icon rainbow-colored.

## Required weather conditions

Create icons for all of these conditions:

### Clear / temperature
1. Clear / Sunny Day — bright sun, clean circular center with refined rays.
2. Hot / Very Hot — intense sun with subtle heat-wave distortion or rising heat lines.
3. Mostly Clear — sun with a very subtle atmospheric accent.
4. Cold — cool atmospheric symbol with subtle frost/cold indication.
5. Extreme Cold — stronger frost/ice visual, still minimal and professional.

### Cloud conditions
6. Cloudy — single soft cloud, no sun.
7. Mostly Cloudy — cloud with partially visible sun.
8. Partly Cloudy — clear sun partially behind a cloud.
9. Overcast — layered/cloud-heavy appearance with muted light.
10. Foggy / Mist — horizontal soft mist layers with a small atmospheric cloud cue.
11. Haze — subtle horizontal atmospheric layers, low contrast.

### Rain conditions
12. Light Rain — small cloud with a few thin raindrops.
13. Rain — medium cloud with balanced rain drops.
14. Heavy Rain — darker/heavier cloud with multiple strong rain streaks.
15. Drizzle — very fine, sparse rain marks.
16. Freezing Rain — rain drops with subtle ice/frost accents.
17. Showers — compact cloud with intermittent rain drops.

### Storm conditions
18. Thunderstorm — cloud + clean lightning bolt.
19. Thunderstorm + Rain — cloud + lightning + rain.
20. Severe Thunderstorm — stronger cloud mass + lightning, still elegant and not scary.
21. Squall / Windstorm — cloud with directional wind arcs.

### Wind / atmospheric
22. Windy — three smooth directional wind curves.
23. Strong Wind — stronger/more pronounced wind curves.
24. Dust / Dust Storm — wind curves with tiny dust particles.
25. Smoke / Poor Air — atmospheric horizontal layers with subtle particulate dots.

### Snow / ice
26. Light Snow — cloud + a few small snowflakes.
27. Snow — cloud + balanced snowflakes.
28. Heavy Snow — dense cloud + multiple snowflakes.
29. Sleet — mixed rain and snow symbols.
30. Blizzard — snow-heavy cloud + directional wind.
31. Frost — subtle ice crystal/frost pattern.

### Special
32. Sunrise — rising sun over a minimal horizon.
33. Sunset — setting sun over a minimal horizon.
34. Moon / Clear Night — crescent moon with a few tiny stars.
35. Partly Cloudy Night — crescent moon partially behind cloud.
36. Cloudy Night — moon + cloud, subdued.
37. Rainy Night — moon/cloud + rain.
38. Thunderstorm Night — moon/cloud + lightning.
39. Unknown / Weather Unavailable — elegant question/atmospheric placeholder, not a generic question-mark emoji.

## Icon semantics
Use universally understandable visual metaphors:
- Sun = clear/hot.
- Heat waves = hot.
- Frost/ice = cold/freezing.
- Cloud = cloudy.
- Droplets = rain.
- Fine tiny droplets = drizzle.
- Lightning bolt = thunderstorm.
- Wind arcs = wind.
- Snowflakes = snow.
- Mist lines = fog/haze.
- Crescent moon = nighttime.
- Mixed precipitation = sleet/freezing rain.

## Consistency rules
- Every icon must look like part of one designed family.
- Use the same cloud silhouette language throughout.
- Use the same sun construction throughout.
- Use the same lightning-bolt geometry throughout.
- Use the same snowflake construction throughout.
- Use consistent line weight and corner radius.
- Avoid excessive gradients, shadows and 3D effects.
- Avoid Apple's exact weather icon style and avoid copying any existing icon pack.
- Create an original visual identity for VayuVarta.

## Suggested UI behavior
The icons should work well for:
- Current weather cards
- Hourly forecast
- 7-day forecast
- Weather alerts
- Temperature widgets
- Location cards
- Mobile navigation
- Desktop dashboard
- Notification previews
