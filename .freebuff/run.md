# Vayu Varta — Dev Server Run Doc

## How to reproduce uncommitted artifacts

1. Copy `.env` from the main checkout (already present — `frontend/.env` is not used by Vite, only `backend/.env` matters for the API proxy)
2. Ensure `frontend/node_modules/` is installed:
   ```
   cd frontend && npm install
   ```
3. Ensure `frontend/public/weather-icons-png/` exists (39 PNG icons generated by `frontend/public/generate_png_icons.py`)

## How to run the server

From the **frontend/** directory:
```
npm run dev
```

This starts the Vite dev server on **port 3000** with:
- React hot-module reload
- API proxy: `/api/*` → `http://localhost:8000` (requires backend running separately)

The backend must also be running:
```
cd backend && uvicorn main:app --reload --port 8000
```
